## Inside a Computer System
16 Nov - Pre Security > Computer Fundamentals

This room have a 3d display of a desktop computer for us to learn the basics part of a computer. It gives us a goal of assembiling a scatterd pieces of the desktop computer for us to find out whats inside of it.

CPU: Or also known as Central Processing Unit is the brain of the computer. It basically allows computer to process the given requests.
Motherboard: It makes the components corespond with each other. Make the work in harmony.
GPU: Also known as Graphics Processing Unit is what renders graphics and video. It is also capable of runing thousands of small calculations very quickly.
Power Supply Unit: It converts AC electricity to DC electricity which the components use.
SSD: Known as Solid State Drive is keeping the data permanently. So after a shutdown data stays protected.
RAM: Also called Random Access Memory, temporarily stores what the computer working on. When the system gets shut down, it erases itself.
Network Adapter: It sends and receives data over network. Without it the computer can't become online.

## Client-Server Basics
16 Nov - Pre Security > Computer Fundamentals

This room gaves us a surface level information on how the internet works and what parts it have.
It start of with a pizza delivery example, where such a simple thing like getting a pizza from a pizza place has its each step that make it a whole deep system.

Service: Is what we are trying to recieve.
Client: Is the one that request the service.
Server: Is the one that serves the service.
Protocol: It defines how a client can communicate with a server.
Port: It is used to identify what type of service running on a system.
DNS: Which stands for Domain Name System, takes the name that client gave and resolves it in to the IP(Internet Protocol), which is the address of the service.
GET: This is a method to retrieve a resourse from a web server.
Scheme: It tells us which protols being used.
Host: Tells us the name of the host we request resources from.
Filename: Is the name of the type of resource we are requesting from the host.
Address: It tells us the IP address where the website is.
Status: It is a indication whether the request was successful or not.
